# ⚡ Fitin60 — 60-Minute Hyper-Local Fashion Delivery

*Fitin60* is a lightning-fast, hyper-local fashion delivery web application designed to connect local clothing boutiques, customers, and delivery fleets within a 15-kilometer radius for rapid 60-minute deliveries.

---

## 🚀 Key Features & Architecture

The project is structured into three independent, fully interlinked web portals powered by *Firebase Realtime Database*:

1. *🛍️ Customer Portal (index.html)*
   - Browse local boutiques, uniforms, kids wear, sarees, kurtis, and men's wear.
   - Seamless "Buy 60M" express checkout experience.
   - Live order tracking and updates.

2. *🏬 Partner Hub (partner.html)*
   - Dedicated dashboard for store owners.
   - Manage inventory, add new fashion products, and oversee incoming orders.
   - Update order status to "Ready for Delivery".

3. *🛵 Rider Fleet (rider.html)*
   - Live 15KM delivery radar for registered express riders.
   - Real-time order pickup and 4-digit OTP verification for secure deliveries.
   - Earnings tracker and duty status control (Online/Offline).

---

- *Backend & Database:* Firebase Realtime Database
